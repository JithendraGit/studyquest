
# StudyQuest

A game-based learning platform designed to make studying more engaging.

StudyQuest aims to combine interactive learning with game-based experiences to help students practice concepts and build confidence across subjects.

## Getting Started

### Requirements

- Node.js (LTS recommended)
- npm

### Run the website locally

From the website project directory, install dependencies if needed:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

### Development

The main homepage is located at `app/page.tsx`. The page updates automatically when you save changes.

Shared layouts and global styles are managed through the files in the `app` directory.

## Technology

- Next.js
- React
- TypeScript
- Tailwind CSS

## Project Status

StudyQuest is under development. Features and design may change as the project evolves.
